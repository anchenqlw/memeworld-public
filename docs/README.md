# 文档目录

本目录保存 Me&Me 对外公开的方法与技术笔记，不包含产品源代码、内部运维配置、用户数据或敏感凭据。

## 内容

- `qca-best-practices.md`：从 Me&Me 实践中提炼的 QCA 长期 Agent 设计原则。
- `software-self-evolution.md`：反馈驱动、自进化控制面、人工闸门与熔断机制。
- `technical-notes.md`：少量关键技术实现与安全边界。

## 写入规则

- 使用简体中文；
- 只公开经过脱敏、不会暴露内部资源与用户隐私的内容；
- 不把目标态写成已经上线的事实；
- 重要结论需要说明适用边界与失败保护。
