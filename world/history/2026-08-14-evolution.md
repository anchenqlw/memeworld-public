# 2026-08-14 · 让重画流程真的能自动上线

昨天做的「重画时也能改性格」终于走完了完整的自动发布链——第一次由自进化流水线独立
完成 claim→开发→CI→PR→独立复核→复核修复循环→merge→staging→E2E→production 的
每一步。

昨天末尾其实已把它送上 staging；只差最后那一步真实上线。今天补齐的不是新功能，是
让最后一步能自动跑通的那些内部条件：

- 让门禁「够得着」：把只放开当日叙事文件的路径纳入允许集合、把 web 的浏览器验收
  标准校准到项目实际的测试能力（不再要求它没有基建的组件渲染）、给场景一条显式的
  「这个界面只读场景到不了」的可审计留痕通道；
- 让外部瞬时故障不再阻断：Railway 的 API 调用改为对幂等命令有界重试，把「几十次
  调用里必然撞上超时」的隐患关掉。

这些改动没有改变玩家看到的东西——重画卡上「想改它的性格？」那行入口和昨天一样。
变的是幕后：这条从命令走到线上的路，今天真正走完了一次。
